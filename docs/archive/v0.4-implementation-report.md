## 核心功能说明

### 1. CLI 工具

**命令:**
```bash
genui                    # 交互模式
genui --adapter ascii    # 指定适配器
genui --version          # 查看版本
```

**特性:**
- 交互式适配器选择
- 连续 UI 生成
- 友好的错误提示
- 支持 quit/exit 退出

### 2. @register_tool 装饰器

**代码示例:**
```python
from genui import ToolRegistry, register_tool

registry = ToolRegistry()

@register_tool(registry)
def my_tool(param: str) -> str:
    """工具描述"""
    return f"结果: {param}"
```

**实现要点:**
- 装饰器工厂函数，接受 registry 参数
- 内部使用 LangChain `@tool` 转换函数
- 返回原函数，保持透明性

### 3. TestAdapter（Headless 测试）

**测试示例:**
```python
from genui import Renderer
from genui.adapters import TestAdapter

adapter = TestAdapter()
renderer = Renderer(adapter=adapter)
renderer.render(ui_instance)

# 模拟交互
adapter.set_input("username", "test")
adapter.click("login_btn")

# 验证结果
assert "欢迎" in adapter.get_output("message")
```

**核心方法:**
- `click(component_id)` - 模拟点击
- `set_input(component_id, value)` - 模拟输入
- `select(component_id, option)` - 模拟选择
- `check(component_id, checked)` - 模拟勾选
- `get_output(component_id)` - 获取输出

### 4. Wheel 打包

**构建命令:**
```bash
uv build
```

**输出:**
- `dist/genui-0.4.0-py3-none-any.whl` (41 KB)
- `dist/genui-0.4.0.tar.gz` (147 KB)

**安装方式:**
```bash
pip install genui-0.4.0-py3-none-any.whl
pip install genui-0.4.0-py3-none-any.whl[anthropic]
```
