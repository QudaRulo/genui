## 核心功能说明

### 1. 两阶段生成流程

**工具规划阶段:**
- LLM 分析用户需求, 识别所需的工具
- 返回工具名称列表和用途说明

**UI生成阶段:**
- 基于选定的工具生成 UI 配置
- 自动生成调用工具的事件处理代码

### 2. Tools 系统架构

```
ToolRegistry (工具注册表)
    ├── 管理所有可用工具
    ├── 支持内置工具自动加载
    └── 支持用户自定义工具注册

ToolExecutor (工具执行器)
    ├── 同步执行工具调用
    ├── 错误处理和结果返回
    └── 集成到 Renderer

Builtin Tools (内置工具)
    ├── Calculator: calculate, convert_unit
    ├── Query: get_weather, get_current_time
    └── File Operations: read_text_file, list_directory
```

### 3. LangChain 迁移

**迁移内容:**
- `LLMClient` 完全迁移到 LangChain
- 支持 `ChatOpenAI` 和 `ChatAnthropic`
- 统一的工具抽象 (`@tool` 装饰器)
- 保持向后兼容

**依赖变更:**
- 移除: `openai` SDK
- 添加: `langchain-core`, `langchain-openai`
- 可选: `langchain-anthropic`

### 使用示例

**基础使用 (v0.1/v0.2 风格, 仍然有效):**
```python
from genui import UIGenerator, Renderer

generator = UIGenerator()
ui = generator.generate("创建一个登录界面")
renderer = Renderer()
renderer.render(ui)
```

**带 Tools 使用 (v0.3 新特性):**
```python
from genui import UIGenerator, Renderer, ToolRegistry

# 自动加载内置工具
registry = ToolRegistry(load_builtin=True)
generator = UIGenerator(tool_registry=registry)

ui = generator.generate("创建一个天气查询界面")
renderer = Renderer()
renderer.render(ui)
```

## 已知问题和限制

### 技术债务

1. **Pydantic 配置警告**
   - 问题: 使用旧式 `class Config`, Pydantic 2.x 已弃用
   - 影响: 生成警告但不影响功能
   - 修复: 需迁移到 `ConfigDict`
   - 优先级: 低

2. **测试环境警告**
   - 问题: `VIRTUAL_ENV` 环境变量不匹配
   - 影响: 仅警告, 不影响测试执行
   - 修复: 配置环境变量
   - 优先级: 低

### 功能限制

1. **工具执行模式**
   - 当前: 仅支持同步执行
   - 限制: 长时间运行的工具会阻塞UI
   - 改进: 考虑异步执行支持

2. **工具选择机制**
   - 当前: LLM 自主选择工具
   - 限制: 可能选择不准确
   - 改进: 增加工具使用示例和约束

3. **错误处理**
   - 当前: 基础错误捕获和显示
   - 限制: 错误信息可能不够友好
   - 改进: 增强错误提示和恢复机制
